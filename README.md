# IPL-Data-Analysis-SQL
IPL Data Analysis using SQL
Analyzed IPL match, ball-by-ball, player, and venue data using SQL to understand team performance, player performance, and factors influencing match results.
Applied Joins, Aggregate Functions, CTEs, Subqueries, CASE statements, and Window Functions to solve real-world analytical questions.
Used LAG() to compare team performance across seasons and identified key insights such as a 54.84% win percentage for teams choosing to field first, along with top-performing players and bowling trends.
Provided data-driven recommendations related to player selection, venue-based performance, team balance, and strengthening the bowling attack.
